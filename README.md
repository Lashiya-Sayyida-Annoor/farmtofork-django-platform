# 🌾 Farm to Fork

## Overview

Farm to Fork is a Django-based web platform that connects small-scale organic farmers directly with consumers. The project aims to reduce the role of middlemen, helping farmers receive fair prices while making fresh produce more accessible to customers. It also includes a Firebase-integrated Android application.

## Features

- Farmer & Customer Registration/Login
- Product Management
- Shopping Cart
- Order Management
- Search & Filtering
- Admin Dashboard
- Firebase Authentication & Storage
- Payment Integration
- Bill Generation
- Android Mobile Application

## Technologies Used

- Python
- Django
- MySQL
- Firebase
- HTML
- CSS
- JavaScript
